# Template i wygląd

## Stan początkowy

Początkowo aktywny był template `roundbox`.

Uwagi:
- wizualnie stary
- ciężka kolorystyka
- mało nowoczesny wygląd
- słaba baza do dalszego dopracowania

## Template docelowy

Docelowo wybrany template: `sprintdoc`.

Powody wyboru:
- nowocześniejszy wygląd
- responsywność
- standardowy mechanizm `sidebar`
- lepsza baza pod porządną nawigację i prostszy layout

## Zadania

- [ ] wykonać backup przed zmianą
- [ ] zaktualizować sprintdoc do najnowszej wersji
- [ ] aktywować sprintdoc
- [ ] sprawdzić wygląd strony startowej
- [ ] sprawdzić działanie sidebara
- [ ] dopracować kolory i układ

## Decyzje projektowe

Kierunek wizualny:
- spokojny, jasny wygląd
- klimat notatnika / książki kucharskiej
- lepsza czytelność niż w roundbox
- prosty sidebar bez przesadnego drzewa nawigacji
